RUN THIS INTERFACE WITH GITHUB COPILOT + JAVA 1.8

One-time setup
1. Use your support team's approved VS Code, GitHub Copilot Agent access and Java 1.8.
   An existing Java 8 JRE or JDK folder is sufficient. No compiler, Python, Node.js,
   PowerShell scripts, extra modules or administrator access are required by this pack.
2. Extract the ZIP to a local writable folder. Open java-home.properties in a text editor.
   Set java.home to the Java 1.8 folder containing bin\java.exe, for example:
   java.home=C:\Program Files\Java\jre1.8.0_XXX
   Use your real folder. No surrounding quotes or doubled backslashes. Save as UTF-8.
   This setting applies only to this pack; it does not change your machine's Java setup.
3. Open the whole extracted copilot-mapping-poc folder in VS Code and sign in to Copilot.
   No separate AI API key is needed. Company policies still apply. If execution is blocked,
   ask support for an approved deployment; do not bypass execution or application policies.

Each run
1. Have one sentence describing the interface's business purpose ready.
2. In Copilot Chat, select Agent mode and send /map-interface.
3. Give Copilot the purpose and clarifications in chat. It saves them, checks the inputs,
   analyses the mapping and generates Report.html. Missing inputs block the run.
4. Open Report.html in your browser. Give corrections in chat and run /map-interface again.

The report is read-only. Unrelated answers are preserved when a decision changes.
Last-review.html retains the last completed review if a later run fails; it may be outdated.
You do not need to edit JSON or type commands. Understanding.txt, Questions.txt and
Decisions.csv remain available if you prefer editing the human-readable files directly.

If /map-interface is not listed, ensure the folder containing .github is open and your
VS Code/Copilot setup supports skills. Fallback in Agent mode:
"Read RUN.md and generate Report.html for this interface."
