SOURCE TO SHOPIFY — START HERE

1. Open this entire folder in VS Code with Copilot Agent mode.
2. Supply the XML or business contract in Current/Source.
3. Run /map-interface. Copilot finds suitable Shopify APIs and maps the attributes.

If you already know the Shopify API, paste its URL in chat. Otherwise Copilot researches it.
No documentation collection, internal JSON editing or per-field approval is needed to see
a draft. The report shows actual destinations, examples, rules and focused open questions.
Proposed custom fields are labelled separately from native Shopify fields and lookups.

Open Report.html. It is read-only. Give clarifications in chat and rerun /map-interface.
Copilot saves your answers and updates affected mappings. Confirmed decisions remain separate
from proposals; the last successful review is preserved through failed reruns.

One-time team setup: set java.home in java-home.properties to an approved Java 1.8 folder.
Spaces are supported; the Java installation path must be ASCII. No extra runtime modules,
administrator access or policy bypass. See TESTING.md for checks and known limitations.
