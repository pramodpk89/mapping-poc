# Shopify API discovery

The agent researches suitable Shopify APIs from the source XML/contract and proposes concrete
attribute mappings. If you have a preferred API, paste its URL in Copilot chat; the agent
opens it and retrieves the relevant fields and requirements. You do not need to choose an
operation/version in advance, collect documentation or maintain internal files.

The report distinguishes native Shopify attributes, lookups and proposed custom fields.
Business uncertainty is attached to affected mappings instead of stopping the whole draft.
Agent-recommended APIs and custom keys are design proposals, not customer confirmations.

Docs/ and Target-reference.json preserve earlier research. They are optional references,
not default choices or mandatory setup. Current research and selection reasons are maintained
by the agent. No live ERP/Shopify writes are part of this workflow.
